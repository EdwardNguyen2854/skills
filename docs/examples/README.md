# Worked examples

These examples are illustrative, not transcripts of executed sessions. They show the expected shape of a short plan, approval, checks and delivery status. Do not copy a claimed result into a record without running the corresponding check.

- [A one-line fix with a short plan](./tiny-fix.md)
- [Planning only, with no implementation](./planning-only.md)
- [A read-only review](./read-only-review.md)
- [One bounded delegated update](./delegated-update.md)

Each example assumes records are optional. When records are declined, the same information stays in the conversation and live tasks, and durable resume is explicitly limited.
