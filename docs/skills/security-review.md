# Review security and risk

`/security-review`

Examines access, private data, secrets, inputs, uploads, dependencies, data loss and operational risk, and explains impact plainly.

## Use when

- The owner requests a security/risk review.
- A feature handles private data, authentication or uploads.
- Before exposing a feature to other users.

## Outcome

Evidence-based findings with severity, plain-language impact, mitigations, limitations and readiness status.

## Key safeguard

It does not probe production or upload source without permission, and a scanner pass is never presented as a security guarantee.
