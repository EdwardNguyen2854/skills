# Clean up and organize

`/tidy`

Audits seemingly unused files and confusing layout, then performs scoped, recoverable cleanup with reference and build checks.

## Use when

- The owner asks to remove unused files or organize the project.
- A layout review is part of approved work.
- Cleanup is needed for a professional, understandable repository.

## Outcome

A cleaner project with preserved uncertain/user/secret material, updated references and verified entry points.

## Key safeguard

No import match is not proof of disuse; broad deletion, user data, secrets and unknown dependencies require specific permission and recovery.
