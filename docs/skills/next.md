# Move the next update forward

`/next`

Finds one evidence-backed next update and, when the owner authorizes judgment-based progress, reviews the plan and carries it through verified agent-reviewed delivery.

## Use when

- The owner asks what to do next.
- The owner says plan, review, implement and go.
- A new release/update should move forward without manual stage handling.

## Outcome

One bounded update implemented, tested and reviewed, or a clear blocked/permission decision. The workflow then stops.

## Key safeguard

It does not invent product demand, start an endless loop, assume upload/merge/release permission, or select another update automatically.
