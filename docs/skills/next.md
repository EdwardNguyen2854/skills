# Move the next update forward

`/next`

Finds one evidence-backed next update and, when the owner authorizes judgment-based progress, reviews the plan and carries it through verified agent-reviewed delivery.

## Use when

- The owner asks what to do next, or asks for a plan only.
- The owner gives an explicit bounded "plan, review, implement and go" grant.
- A previously approved update should continue.

## Outcome

One bounded update implemented, tested and reviewed, or a clear blocked/permission decision. The workflow then stops.

## Key safeguard

It does not invent product demand, start an endless loop, treat "continue" or a bare "go" as approval of an unseen plan, assume upload/merge/release permission, or select another update automatically.
