# Improve UI and UX

`/ui-ux`

Improves real user journeys, clarity, states, accessibility, responsiveness, interaction feedback and visual quality.

## Use when

- The owner asks for UI/UX or usability improvement.
- Users struggle with a flow.
- A feature needs interface review before delivery.

## Outcome

Prioritized interface improvements with before/after evidence, accessibility/responsive checks and known limitations.

## Key safeguard

It preserves branding and scope, validates real interactions rather than screenshots alone, and does not force an unrelated redesign.
