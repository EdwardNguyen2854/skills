# handoff

`/handoff` captures current state for another agent or a future session.

It preserves issue, branch/worktree, progress, incomplete work, risks, validation, and exact next step.

## Use When

- The user wants to pause work.
- Another agent will continue.
- A long task needs a durable issue comment or temporary note.

## Output

A handoff with current issue, current branch/worktree, goal, done, not done, important context, problems/risks, validation, and next step.

## Important Rule

Be factual. Do not make progress sound more complete than it is.
