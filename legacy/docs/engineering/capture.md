# capture

`/capture` turns a rough idea into a GitHub Issue or improves an existing issue.

It is the intake step for features, bugs, tasks, experiments, research, and large AI run notes.

## Use When

- The user has an idea but no issue yet.
- An existing issue is too vague to plan from.
- A bug report needs expected behavior, actual behavior, reproduction steps, impact, and acceptance criteria.

## Output

A structured issue with goal, user value, scope, acceptance criteria, notes, and open questions.

When enabled in `docs/agents/issue-tracker.md`, capture also applies Project status and milestones.

## Important Rule

Capture does not implement. It preserves enough context for `/plan` to work.
