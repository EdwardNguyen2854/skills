# Engineering Skills

User-invoked skills for issue-first AI development.

| Skill | Purpose |
|---|---|
| [`setup`](./setup/SKILL.md) | Set up a repository for the issue-first workflow. |
| [`capture`](./capture/SKILL.md) | Turn ideas into GitHub Issues. |
| [`plan`](./plan/SKILL.md) | Plan implementation without changing code. |
| [`start`](./start/SKILL.md) | Create an isolated branch or worktree. |
| [`build`](./build/SKILL.md) | Implement the approved plan only. |
| [`review`](./review/SKILL.md) | Review completed work before merge. |
| [`fix-review`](./fix-review/SKILL.md) | Fix only review findings. |
| [`ship`](./ship/SKILL.md) | Merge, update records, and close the loop. |
| [`discover`](./discover/SKILL.md) | Map unclear work before planning. |
| [`spec`](./spec/SKILL.md) | Create or update release specs. |
| [`handoff`](./handoff/SKILL.md) | Preserve state for a later session. |
