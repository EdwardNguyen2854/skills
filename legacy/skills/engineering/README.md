# Engineering Skills

Historical record of the previous issue-first workflow. These files are renamed `SKILL.historical.md` so installers that discover `SKILL.md` do not activate them. They are not part of the active collection.

| Skill | Purpose |
|---|---|
| [`setup`](./setup/SKILL.historical.md) | Set up a repository for the issue-first workflow. |
| [`capture`](./capture/SKILL.historical.md) | Turn ideas into GitHub Issues. |
| [`plan`](./plan/SKILL.historical.md) | Plan implementation without changing code. |
| [`start`](./start/SKILL.historical.md) | Create an isolated branch or worktree. |
| [`build`](./build/SKILL.historical.md) | Implement the approved plan only. |
| [`review`](./review/SKILL.historical.md) | Review completed work before merge. |
| [`fix-review`](./fix-review/SKILL.historical.md) | Fix only review findings. |
| [`ship`](./ship/SKILL.historical.md) | Merge, update records, and close the loop. |
| [`discover`](./discover/SKILL.historical.md) | Map unclear work before planning. |
| [`spec`](./spec/SKILL.historical.md) | Create or update release specs. |
| [`handoff`](./handoff/SKILL.historical.md) | Preserve state for a later session. |
